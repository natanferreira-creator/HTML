# HTML
1. Como você montou a estrutura básica do arquivo index.html? Explique a função de <!DOCTYPE html>, <html>, <head> e <body>.

R: Comecei o código com <!DOCTYPE html>, que indica que estou usando HTML5. Depois coloquei a tag <html>, que contém toda a página. A tag <head> possui as configurações da página e a tag <body> possui o conteúdo que aparece no navegador.

2. O que você colocou dentro do <head> e qual é a função de cada elemento utilizado?

R: Dentro do <head> coloquei o charset UTF-8, que permite utilizar acentos e caracteres especiais. Também coloquei o viewport, que ajuda a página a funcionar em diferentes tamanhos de tela, e o <title>, que define o nome da página. Por último, coloquei o <style> para fazer a parte visual da página.

3. Como você utilizou as duas <div> para separar e organizar os conteúdos da página? Informe também os nomes das classes criadas.

R: Usei duas <div> para separar os conteúdos da página. A primeira possui a classe perfil e contém minhas informações e meus interesses. A segunda possui a classe objetivos e apresenta o que quero aprender sobre tecnologia.

4. Como você aplicou o CSS dentro da tag <style>? Apresente um seletor, uma propriedade e um valor existentes no seu código.

R: Usei o CSS dentro da tag <style> para mudar as cores e organizar a página. Um exemplo é .Perfil, onde usei background-color: white; para deixar o fundo da primeira parte branco. Também usei color, padding e border.

5. Quais cores e propriedades visuais você escolheu e qual foi o resultado observado no navegador?

R: Escolhi cores simples como azul, verde, vermelho, roxo, branco e cinza. Usei background-color para mudar o fundo, color para mudar a cor dos textos, padding para criar espaços e border para colocar bordas. O resultado foi uma página simples e organizada.

6. Qual alteração ou correção foi necessária depois que você testou a página? Caso não tenha ocorrido erro, explique como realizou o teste.

R: Salvei o arquivo com o nome index.html e abri ele no navegador. Depois conferi se os textos, as cores, as bordas e as duas partes da página estavam aparecendo corretamente. Como o código funcionou, não foi necessário fazer nenhuma correção.
